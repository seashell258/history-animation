# 越王的十年 — Beat Sheet

Pre-production Step 2 產物。**場景 code 的所有 timing 以本檔為準,不得在 code 裡即興。**

情緒弧:歸鄉平靜 → 沉溺舒適 → 憶苦驚醒 → 決意站立 → 十年砥礪 → 蓄勢
自動段總長約 **50 秒**,加上 ritual 的玩家操作時間(最快 9 秒)。

## 主表

| # | 場景 | 秒 | 事件序列 |
|---|------|----|----------|
| 0 | **start** | 等待 | 標題「越王的十年」+ 副標「臥薪嘗膽・春秋動畫」+「開始上課」鈕。點擊解鎖 Web Audio |
| T0 | **transition 0→1** | 1.0 | **手法:標題退場 + 全黑**。0–0.5s 標題與按鈕淡出並輕微上移 / 0.5–0.7s 全黑 / 0.7–1.0s 交棒給 homecoming 的淡入。因果:單純的幕啟,不做花俏處理 —— **第一個真正的手法要留給 T1** |
| 1 | **homecoming** | 7.0 | 0–1.0s 黑場淡入,**油燈火光先亮**(光先於人) / 1.0–2.5s 范蠡、文種自下淡入跪迎,身體輕微前傾 / 2.5–5.0s 勾踐自右側走入至中央偏右,步伐 4 步 / 5.0–7.0s 停步,字幕淡入「三年為奴,夫差終於放他回越國。」 / 7.0s+ 提示「點一下,繼續」呼吸閃爍 |
| T1 | **transition 1→2** | 1.8 | **手法:字卡 + 光源橋接**。0–0.6s 油燈火焰放大成滿版暖光,人物在暖光中淡出 / 0.6–1.2s 黑底金字「回國之後」 / 1.2–1.8s 字卡淡出,comfort 自同一片暖光中浮現。因果:**燈的暖 → 舒適的暖**,用同一個光源當橋,不是硬切 |
| 2 | **comfort** | 7.0 | 0–1.5s 榻與屏靠淡入,勾踐**已經癱在榻上**(不演坐下,一開始就沉了) / 1.5–3.0s 侍者自右走入,雙手呈碗 / 3.0–4.5s 碗交到勾踐手心,他抬手就口 / 4.5–7.0s 全場靜止,字幕「日子舒服了。他快要忘記那三年。」**這場的節奏刻意拖慢 —— 無聊感是設計的一部分** |
| T2 | **transition 2→3** | 1.4 | **手法:match cut(碗)**。0–0.5s 碗以外的一切淡出,碗的螢幕座標鎖住不動 / 0.5–1.0s 碗由 `bowl-full` 換成 `bowl-empty`,同時下墜到地面高度 / 1.0–1.4s turning 淡入(同一張榻,但勾踐已坐直)。因果:**同一個碗,從「捧著」到「放下」**,物件自己承擔時間與心境的轉換 |
| 3 | **turning** | 8.0 | 0–1.2s 承接 match cut,勾踐已是跪坐端正,空碗在地上 / 1.2–2.2s 月光窗亮起,視線被拉過去 / 2.2–2.5s **硬切進閃回**(0.12s 白閃),冷調 overlay 罩上 / 2.5–4.5s 閃回:夫差高踞左側俯視,勾踐在右下伏地做工 / 4.5–4.8s 硬切回現在 / 4.8–6.0s 姿態不變但**畫面震一下**(記憶打到他) / 6.0–8.0s 字幕「他想起馬廄裡的那個自己。」 |
| T3 | **transition 3→4** | 1.6 | **手法:鏡頭推 + 全黑 + 拉開**。0–0.7s 向勾踐的臉推近(scale 1 → 1.35),暖光同步抽離轉冷 / 0.7–1.0s **全黑 0.3s** / 1.0–1.6s 拉回原景別,他**已經站著**,榻被推到畫面右側壓暗。因果:推近=進入內心,黑=決定發生的瞬間,拉開=決定已是事實。**不用旁白解釋** |
| 4 | **decision** | 6.0 | 0–1.0s 勾踐站定,腳下有影 / 1.0–2.2s 薪自左下滑入、膽自右上垂落(彈性 cubic-bezier) / 2.2–3.2s 范蠡、文種自兩側淡入立於後方(見證) / 3.2–4.2s 字幕「他要自己每天都記得。」 / 4.2–6.0s 操作提示「左右各按住不放」淡入 |
| T4 | **transition 4→5** | 1.2 | **手法:原地暗轉 + 背景置換 + 音效橋**。0–0.8s 配角與榻淡出,背景**換成馬廄冷調**(記憶成為背景),遠鼓自 0 淡入 / 0.8–1.2s 勾踐由站立換成跪坐(他蹲下來開始儀式)。因果:**空間不變、人物不變,只有背景變成記憶** —— 表示他把那段記憶擺在眼前,每天面對 |
| 5 | **ritual** | 玩家控制<br>(最快 9.0) | **核心關卡。詳細規格見下方〈ritual 關卡設計〉。**<br>玩家必須**把手掌張到最開**,同時按住畫面**最左下的薪**與**最右下的膽**(相距約 1020px = 幾乎整個畫面寬)。撐開手掌的物理吃力感,就是這一集要傳達的「辛苦」。<br>按住期間,**畫面中央中上方的記憶面板持續播放馬廄受辱的畫面** —— 他一邊撐著,一邊看著那個過去。<br>進度 **0→0.33** 跪坐,金光 0→.27,鼓 0→.33 / **0.33→0.66** 交叉溶接到起身,金光 .27→.54 / **0.66→1.00** 交叉溶接到站立,金光 .54→.82,鼓 →1.0 / 滿進度 → 上行和弦,0.82s 後轉場 |
| T5 | **transition 5→6** | 4.6 | **手法:金光吞沒 + 三段字卡**。0–0.8s 金光自中心擴散到滿版,記憶面板在光中溶掉 / 0.8–2.0s 字卡一「就這樣,勾踐在臥薪嘗膽的辛苦日子裡,」/ 2.0–3.4s 字卡二「時刻提醒自己 —— 要讓越國強起來。」/ 3.4–4.2s 字卡三「十年後,他終於……」/ 4.2–4.6s 字卡淡出,金光收束成 ending 的中央光暈。因果:**玩家按出來的進度光,直接轉成十年的時間流逝**;三段字卡把「每天重複」壓縮成一句話 |
| 6 | **ending** | 4.4 | 0–0.3s 黑 / 0.3–1.4s 十年後的勾踐自光暈中淡入(白鬚、灰髮) / 1.4–2.7s 大字「十年。」淡入 / 2.7–4.4s 字幕「他終於等到了那一天。」 / 4.4s+「繼續 →」鈕淡入 |

## ritual 關卡設計(本集的核心)

這一關要傳達的不是「按住等進度條」,而是**辛苦**。手段是身體性的:
**逼玩家把手掌張到最開**,並且在他撐著的時候,把他撐苦的理由擺在正上方給他看。

### 版面(stage 1280×720)

```
┌──────────────────────────────────────────────┐
│              ┌────────────────┐              │
│              │  記憶面板       │  ← 馬廄受辱回憶  y 24–304
│              │  夫差俯視       │     x 390–890(置中偏上)
│              │  勾踐伏地做工   │                        │
│              └────────────────┘              │
│                                              │
│                   勾踐(現在)                 │  ← x 540–740, y 340–680
│                   跪坐→起身→站立              │
│                                              │
│  ▣薪                                    ▣膽 │  ← 兩個互動點在最外側
└──────────────────────────────────────────────┘
   x 20–270                          x 1090–1240
   y 560–719                         y 470–700
```

垂直構圖是刻意的:**過去壓在上面,他在下面撐著,薪與膽在兩邊是每天的功課。**

### 互動規格

| 項目 | 值 | 理由 |
|------|-----|------|
| 薪的位置 | 左下角 `(20, 560)` 尺寸 250×159 | |
| 膽的位置 | 右下角 `(1090, 470)` 尺寸 150×230 | |
| 兩點中心距離 | **約 1020px ≒ 畫面寬的 80%** | **這是關鍵數字** —— 逼手掌張到最開 |
| 判定區 | 道具外擴 40px padding | 國小生手指精準度不足,不要用視覺邊界當判定 |
| 累積條件 | **兩點必須同時按住** | 單邊按住 0 累積 |
| 放開 | **進度不倒退**,但金光與鼓聲立刻衰減 | 不倒退是對小朋友的仁慈;但「光暗下去」讓他知道鬆手是有代價的 |
| 滿進度時間 | 9 秒(`progress += dt/9`) | 沿用 v1,實測對國小生是「撐得住但會酸」 |
| 薪的漂移 | 左右 ±40px,週期約 7s | 目標會動 → 手要跟著調整 → 更累 |
| 膽的漂移 | 上下 ±28px,週期約 5.2s | 與薪不同週期,兩手不能用同一個節奏 |

### 記憶面板

按住期間持續播放(不是靜止圖):

- 內容:`stable-bay`×3 + `stable-trough` 當背景,`fc-looming` 在左、`gj-laboring` 在右下
- **3.5 秒循環一次**:夫差由 `fc-looming` 切到 `fc-pointing`(指令下達),勾踐 `gj-laboring` 做一次緩慢的伏地起伏
- 冷調 overlay(`#0d1a24` 約 0.45)+ 四周暗角,讓它讀起來是**記憶**而不是主場景
- 面板隨進度**逐漸變亮、變清晰**(冷調 overlay 由 .45 → .15)—— 他撐得越久,越是直視那段過去
- 進度滿 → 面板被金光溶掉

### 與 turning 的關係

turning 場的閃回是**第一次**看到這段記憶:短、硬切、驚嚇。
ritual 的記憶面板是**第二次**:長、持續、被他主動看著。
同一批 asset,兩種用法 —— 前者是被記憶襲擊,後者是選擇面對它。

## 互動點

| 場景 | 互動 | 說明 |
|------|------|------|
| start | 點「開始上課」 | 同時解鎖 Web Audio |
| homecoming | 點畫面任意處 | 玩家自己決定何時離開這份平靜 |
| comfort | 無(自動前進) | **刻意不給互動** —— 沉溺的時候人是被動的 |
| turning | 點畫面任意處 | 閃回結束後才可點 |
| decision | 無(自動前進) | |
| ritual | **手掌張到最開,同時按住最左下的薪與最右下的膽** | 核心 mechanic。兩點相距畫面寬的 80%,**撐開手掌的吃力就是「辛苦」本身** |
| ending | 點「繼續 →」 | 第三幕未實作,暫無動作 |

comfort 不給互動是刻意的:**這集唯一需要玩家出力的地方是 ritual**,前面越被動,那個對比越強。

### 情緒四拍(使用者指定的敘事骨架)

| 拍 | 要讓觀眾感覺到 | 對應場次 |
|----|----------------|----------|
| 1 | **他回來,感到舒服** | homecoming → T1 → comfort |
| 2 | **他自己覺得「不行!」** | turning → T3 → decision |
| 3 | **辛苦**(玩家親手撐出來的) | ritual |
| 4 | **就這樣過了十年** | T5 字卡 → ending |

第 3 拍是全片的重心 —— 前兩拍是為了讓玩家願意撐,第 4 拍是給撐完的回報。

## 本 beat sheet 修掉的 v1 問題

| v1 問題 | 修法 |
|---|---|
| homecoming → comfort 無過場,硬切 | **T1** 用油燈的光當橋,暖接暖 |
| turning → decision 無過場,他突然就站著了 | **T3** 推近 → 全黑 → 拉開,把「決定」演成一個可見的瞬間 |
| timing 只散在 code 裡,沒有文件 | 本檔即規格,code 從這裡抄 |
| comfort → turning 只是換場景 | **T2** 改成碗的 match cut,讓物件承擔轉折 |
| ritual 姿態變化是 code 裡即興的 rotate | 綁定三個 asset symbol 的交叉溶接,進度分段寫死在此表 |
| v1 的薪膽放在 `left:148px` / `right:148px`,兩點距離不夠,手不用張開 | 移到**畫面最外側兩角**,中心距離拉到畫面寬的 80% —— 辛苦感從此有身體基礎 |
| v1 的 ritual 只有靜態馬廄當背景,玩家撐的時候沒有理由 | 改成**中上方的記憶面板持續播放受辱畫面**,且隨進度變清晰 —— 撐著的理由一直在他眼前 |
