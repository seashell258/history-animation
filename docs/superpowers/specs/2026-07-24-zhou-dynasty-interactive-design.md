## 1. 整體故事

**主線：越王勾踐臥薪嘗膽**

夫椒之戰敗給吳王夫差 → 被帶去吳國當馬夫三年 → 回越國後用薪和膽提醒自己不忘屈辱 → 謀略十年重建越國 → 滅吳稱霸

**教學定位**：讓學生理解「臥薪嘗膽」這四個字的由來與情感邏輯；老師口頭帶出春秋爭霸背景與歷史意義。動畫自己把故事說清楚，老師做教學，不補劇情。

## 5. 第二幕詳細設計：臥薪嘗膽

### 5.1 前提（第一幕已建立）

學生進入第二幕時已知：
- 夫椒之戰，勾踐敗給吳王夫差
- 被帶去吳國替夫差養馬，受盡屈辱
- 夫差認為他已被馴服，放他回越國

第二幕不重複交代以上背景。

### 5.2 場景流程

**場景 A：回家**
- 畫面：越國宮殿暖光，臣子跪迎，勾踐走進門
- 字卡：「終於，夫差放他回家了。」
- 操作：點一下，進場景 B

**場景 B：逍遙（純視覺，無字卡）**
- 畫面：勾踐坐在軟榻，侍者端來熱食，他放鬆享用
- 音效：溫暖的室內氛圍聲
- 停留約 2–3 秒讓學生感受舒適，再自動接場景 C

**場景 C：轉折（點選推進）**
- 畫面：勾踐放下碗，眼神飄向窗外，表情由鬆轉緊
- 閃回：吳國馬廄黑白冷調剪影一瞬（冷光、陰暗）
- 音樂驟停
- 無字卡，純動作與表情說明內心
- 操作：點一下（或停頓後自動接）

**場景 D：決定（動畫，無互動）**
- 畫面：勾踐把軟榻推到一旁；走出去，帶回一捆薪草（左）和一顆苦膽（右）；放在自己面前，坐下
- 薪草從左側、苦膽從右側滑入畫面底部定位
- 無字卡，純動作說明一切

**場景 E：核心互動——雙點同時壓住**

畫面構圖（1280×720）：

```
┌──────────────────────────────────────────┐
│                                          │
│   吳國馬廄記憶閃回（冷調、灰黑）         │  ← 上方約 2/3 高度
│   勾踐剪影從跪坐 → 挺身（進度指標）     │
│                                          │
│                                          │
│  [薪草 ember]           [苦膽 gall]     │  ← 底部，學生雙手壓在這裡
└──────────────────────────────────────────┘
```

互動規則：
- 同時按住薪草（左下）和苦膽（右下）→ 勾踐身影逐漸從彎腰挺直
- 兩個元素各自緩慢漂移，節奏**不同步**（薪左右晃、膽上下動），學生的手需要微調跟上
- 放開任一個 → 進度暫停，不退（不懲罰，讓學生重新跟上再繼續）
- 同時按住累計約 8–10 秒 → 勾踐完全站立，觸發場景 F

上方視覺：
- 背景：馬廄冷調閃回（提醒那段苦）
- 中央：勾踐剪影 posture 動畫（彎 → 挺），是主要進度指標
- 學生雙手在畫面底部，中央視覺區完全可見

音效：
- 按住期間：低沉持續竹篁風聲
- 隨進度積累：遠方鼓點漸入
- 完成瞬間：短促解決感音效

**場景 F：收尾**
- 勾踐完全站立，金光（--gold）從心口向外漫開
- 字卡：「十年。」（僅此兩字，老師展開教學）
- [繼續 →] 按鈕，教師控制何時進下一幕（第三幕尚未實作，先隱藏或淡出）

### 5.3 美術風格

剪紙／皮影風，與商朝一致：手繪 SVG 剪影，純色盤，無外部圖片。

| 場景 | 色調 |
|---|---|
| A–B（回家、舒適）| 暖調 `--warm` `--slip` |
| C–D（轉折、決定）| 冷暖交接，音樂停 |
| E 互動上方（記憶閃回）| 冷調 `--night` 灰黑 |
| E 互動下方（薪膽）| `--ember`（薪）`--gall`（膽） |
| F 收尾（決心金光）| `--gold` |

### 5.4 技術方案

與商朝相同架構：Vanilla JS + SVG + CSS 動畫 + Canvas + Web Audio API
- 舞台：1280×720，transform-origin center，等比縮放
- Pointer events（觸控 + 滑鼠雙支援）
- Web Audio 程式合成音效，手勢解鎖後啟用；無音效時互動仍可進行
- 零外部依賴，離線可用，雙擊即開

### 5.5 互動機制小結

本幕唯一核心機制：**雙點同時壓住（不同步漂移）**

- 商朝四幕未使用過此機制，在系列中為新玩法
- 物理張力（手臂張開）與主題呼應（臥薪＋嘗膽缺一不可）
- 不存在「答錯」狀態，放開不懲罰
